# 📦 Delivery Tracker

A Full-Stack system developed for real-time package tracking, integrating a robust Java API with a dynamic and responsive interface. 

This project was structured using a **Monorepo** architecture, maintaining a clear separation of concerns between the Back-end and the Front-end within the same repository.

## 🚀 Technologies Used

### Front-end
* **Framework:** Angular (Configured with Standalone Components)
* **Language:** TypeScript
* **Styling & UI:** Angular Material & CSS
* **Package Manager:** npm

### Back-end
* **Language:** Java
* **Framework:** Spring Boot (Spring Web, Spring Data JPA)
* **Database:** PostgreSQL
* **Dependency Manager:** Maven
* **Architecture:** REST API

## 📋 Prerequisites

To run this project locally, ensure you have the following tools installed in your development environment:

* [Node.js](https://nodejs.org/) (Version 18 or higher)
* [Angular CLI](https://angular.dev/tools/cli) (Global installation via command: `npm install -g @angular/cli`)
* [Java JDK](https://www.oracle.com/java/technologies/downloads/) (Version 17 or higher)
* [PostgreSQL](https://www.postgresql.org/download/) (Running on the default port 5432)
* [Git](https://git-scm.com/)

**Recommended IDEs:** IntelliJ IDEA (for Back-end) and Visual Studio Code (for Front-end).
